# Security Policy

## Supported versions

FxGrip has no release yet. Security fixes land on `main`.

## Reporting a vulnerability

Report a vulnerability privately through GitHub's [private vulnerability reporting](https://github.com/belisoful/FxGrip/security/advisories/new). Do not open a public issue.

Include the affected files or APIs, the steps to reproduce, and the impact. You receive an acknowledgment when the report is triaged.
